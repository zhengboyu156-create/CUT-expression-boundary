# BCI HER2：ABMIL 结果复核与 PASB 启发的后续实验要求

状态：研究和实施要求，尚未代表功能已实现、实验已完成或病理有效性已证实。记录日期：2026-11-10。

## 1. 目标与现有证据

目标是弄清楚 H&E 生成的虚拟 IHC 在 HER2 分级相关图像分类任务中保留了哪些信息，以及在什么条件下能为 H&E 分类带来增益。虚拟 IHC 并非额外实测模态；测试时若只允许输入 H&E，不能在生成或预测中读取该测试样本的真实 IHC 或真实 HER2 标签。

以下数字由用户提供，为 3 个随机种子的均值 ± 标准差；原始结果文件尚未在本仓库或当前环境中独立核验：

| 输入 | Accuracy | Macro-F1 | QWK |
| --- | --- | --- | --- |
| A：H&E | 0.8854 ± 0.0194 | 0.8730 ± 0.0205 | 0.8064 ± 0.0343 |
| B：虚拟 IHC | 0.7117 ± 0.0332 | 0.6635 ± 0.0384 | 0.5539 ± 0.0602 |
| C：H&E + 虚拟 IHC | 0.8734 ± 0.0021 | 0.8540 ± 0.0108 | 0.8044 ± 0.0058 |
| D：真实 IHC | 0.9185 ± 0.0109 | 0.9071 ± 0.0118 | 0.8873 ± 0.0168 |

- 按提供的均值，C−A 的 Macro-F1 为 −0.0190，即 −1.90 个百分点；Accuracy 为 −0.0120，QWK 为 −0.0020。
- 用户报告 seed 1234 的**图像级配对** Bootstrap：C−A Macro-F1 = −0.0125，95% CI [−0.0413, 0.0164]。该区间包含 0，不是三种子联合区间，也不是病例级区间；不能据此断言有提升、无差异或一定退步。
- 用户指出 HER2 标签来自真实 IHC 判读。D 组适合作为真实 IHC 信息参考，并非严格数学上限或公平的 H&E-only 预测基线。该标签的具体层级、来源和质量仍需依据原始数据文件核实。
- 数据清单目前仅确认存在图像 ID，缺少可信图像到切片/病例映射。禁止把图像视为相互独立患者，禁止将图像级区间称为患者级区间。
- 用户本地存在 `summary.json` 和 `paired_bootstrap_C_minus_A.json`，需由实验执行环境读取并核对；本文件不包含原始数据或结果文件。

## 2. 必须遵循的边界与数据协议

1. 全自动处理完整图像或全部有效组织窗；不人工挑选候选区作为算法输入。可采用预先定义的组织/背景过滤，并记录排除规则和每组覆盖率。
2. 已配对 H&E/IHC 以相同图像和坐标对应：自动分窗时 `he_bbox == ihc_bbox`。本阶段不在区域外检索对应的 IHC 区域，也不声称同坐标等于真实细胞级配准；切片错位、缺失和配准精度仍待核查。
3. 区分实验的测量单位：病例、切片、图像、窗和细胞。记录每级数据量和标签来源。未经实际验证，不把切片级标签当作每个窗的真实 HER2 等级，也不把 DAB 像素当作经病理确认的阳性细胞。
4. 核查生成器、特征提取器、分类器和模型选择各自使用的数据。病例级映射尚不可用时，不声称训练/验证/测试病例独立；不得通过猜测文件名规则制造病例 ID。
5. 检查测试样本是否进入生成器训练、教师/特征提取器训练、阈值确定、分类器训练或调参，包含真实 IHC、标签、预处理统计和可能的权重选择。记录任何无法排除的重叠。
6. 保留训练/验证/测试清单、检查点哈希、随机种子、包版本、图像变换、分类器训练及模型选择规则。先锁定训练和验证方案，再运行最终测试；不得依据测试集挑选阈值、样本、模型或报告最好随机种子。
7. 预先固定输出类别顺序、Macro-F1 和零支持类别的处理规则、QWK 设置以及缺失样本处理，保证 A/B/C/D 测试样本集合和 ID 一致；如不一致应先修复并披露。
8. 原论文可能在生成过程中使用参考 IHC：PASB 的算法 1 将 reference IHC 列为输入。其具体公开代码和测试条件需逐项核实；不可未经核实将参考 IHC 引导结果称作 H&E-only，也不可与 H&E-only 结果混作同条件比较。

## 3. 阶段一：复核现有四组和诊断融合错误

### 输入

- 每个随机种子、各输入组的样本级预测概率、预测标签、真实标签和图像 ID。
- 真实 IHC、虚拟 IHC、H&E 的样本关联清单；如存在切片/患者映射，验证后附来源与版本。
- 生成器、下游模型、数据处理和训练配置；若原始预测未保存，则用对应冻结检查点按已锁定配置重跑并注明。

### 自动输出

- 三种子的逐种子 Accuracy、Macro-F1、QWK 和配对差值 C−A；报告均值与标准差，保留每一次结果。
- 0、1+、2+、3+ 类别的支持数、precision、recall、F1 与混淆矩阵；若标签层级并非图像级，必须显示其真实来源和解释限制。
- 对同一图像分别统计 A、C 的“改对”“改错”“都对”“都错”，按标签分组统计并保留分母。此分析描述测试集表现，不能据此在测试集上训练或挑选融合规则。
- 不以更低的三种子标准差证明模型更准确或更可靠；指标差异由同一样本、同方案对照后评估。

### 交付与验收

输出结构化预测表、汇总表、混淆矩阵与自动报告，能追溯到配置和种子；对 ID 重复、组间错配、标签不一致或预测缺失发出明确错误。无病例映射时只允许标注图像层级。

## 4. 阶段二：病理表达与图像分布评价

对真实 IHC 和虚拟 IHC 使用相同的颜色空间、色彩反卷积、组织过滤和固定参数，按同坐标分窗，全图自动统计：

- 图像/组织窗的 DAB 强度、积分光密度图像代理、阈值阳性面积代理，以及真实与虚拟图像的差异；阈值仅由训练/验证数据或独立规范确定。
- 按现有 HER2 标签分组查看分布、误差和分母；此分组用于分析，不等于窗级病理标注。
- 分析 DAB 统计误差与 A/B/C 分类错误之间的关系；说明相关性不等于因果关系，真实 IHC 与 H&E 的相邻切片错位可能影响比较。
- 可计算 FID/KID 等生成分布指标，并记录特征网络、处理分辨率、参考/生成数量和实现；FID 不能证明对应样本的 HER2 表达正确。
- H-score、阳性细胞率及膜染色定位只有在相关细胞分割、组织类型与病理参考得到验证后才能作为相应指标报告；否则不得使用临床含义的名称。

每种处理同时保存覆盖率、排除原因、输出单位和参数。可自动生成 H&E、真实 IHC、虚拟 IHC、DAB 图及模型预测的配对报告；人工复核用于检查而不作为手选候选区的前置条件。

## 5. 阶段三：对照实验，不预设结果会改善

仅在阶段一、二结果完成后，按预注册方案选择最有根据的对照：

| 组别 | 生成与预测 | 目标 |
| --- | --- | --- |
| G0 | 原 CUT 虚拟 IHC；沿用现有 B/C 分类协议 | 保留原始生成基线 |
| G1 | 原 CUT + 训练阶段表达相关约束；冻结后仅从测试 H&E 生成，再按相同协议评估 | 检查表达相关监督是否改善生成和下游预测 |
| G2 | 保持 G0 生成图不变，只改变融合策略 | 区分融合方式与生成质量的影响 |

- G1 可借鉴 PASB 的病理语义监督思想；真实 IHC 或 IHC 训练的教师仅可按预先划分用于训练。若使用切片级 HER2 标签作为弱监督，明确其标签层级及局限；不将其冒充细胞真值。
- G0/G1 保持数据、生成器容量、训练预算、预处理及下游协议一致；若条件不同须披露。每一组在训练集生成对应图像、在验证集选择模型，再用冻结模型对测试 H&E 推理；明确分类器是重新训练还是冻结迁移。
- G2 的结构、容量、输入特征及训练预算与原 C 尽量匹配；在验证集而非测试集选择权重。必要时使用相同容量的 H&E 重复输入作为容量对照，并清晰标记为对照。
- A、B、C、D 在生成变体中应报告对应定义。D 不参与选优作为测试真值，不把更高的 D 当成虚拟 IHC 实现的证据。
- 主要比较事先指定（建议 C−A 的 Macro-F1）；同时报告 Accuracy、QWK、分类别表现及病理相关指标。完整保留负结果。

## 6. 阶段四：统计与不确定性

1. 病例 ID 未核实时，报告图像级点估计和图像级 Bootstrap，并明确同病例图像相关性可能使区间过窄；不同随机种子的标准差反映训练随机性，不能当作患者抽样置信区间。
2. 获得可信映射后，以病例为重采样单位：每次抽中病例携带其全部相关图像，A/C 使用相同病例重采样；事先定义病例/图像的统计量、重复次数、置信区间算法以及类别缺失的处理。
3. 对冻结的多个种子模型，可在同一病例 Bootstrap 重采样中分别计算各种子 C−A，再在每次重采样内对种子汇总；该区间须说明条件于已训练模型，主要反映测试病例抽样不确定性，不自动涵盖完整训练随机性。逐种子结果仍须单列。
4. 避免以 3 个随机种子充当 3 名独立患者做显著性检验；避免由于区间包含 0 就宣称“等效”或“没有差异”。

## 7. 可视化与参考资料

- t-SNE 仅为辅助可视化。对真实及虚拟图像使用同一固定编码器、统一预处理，将同一次待比较对象共同降维；记录网络、层、采样、参数和随机种子。点云重叠不证明细胞表达或临床可靠性。
- scikit-learn t-SNE 的来源快照和许可证见 `third_party/scikit-learn-tsne/`；该快照不是独立可运行的软件包，也不是 PASB 绘图源码。
- PASB 论文：[Pathology-aware Schrödinger bridge for virtual immunohistochemical staining](https://doi.org/10.1016/j.media.2025.103869)。参考其表达一致性、IOD/HS 差异和下游评估思路；任何复现需核实参考 IHC 输入、标签、模型和评估设置。

## 8. 当前执行顺序

1. 读取并核验现有四组原始预测、划分、训练和生成配置；列出缺失项。
2. 先完成固定测试集的逐种子混淆、分类别和 A/C 配对错误报告。
3. 在明确配对及配准限制后，完成自动 DAB 代理分析。
4. 依据分析预注册 G1/G2；锁定验证与测试协议后执行。
5. 可信病例映射到位后再开展病例级划分与配对置信区间；否则保留图像级结论及其限制。
